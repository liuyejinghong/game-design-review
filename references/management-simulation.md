# 模拟经营专项检查（按需加载）

本附件面向模拟经营、基地经营、生产/物流调度、服务经营（餐厅 / 商店 / 主题公园等）与休闲经营，作为体裁专项与表现形态、平台、引擎独立：2D、3D、文字原型使用同一组测法，结论随当前阶段校准。四把尺子与 P0/P1/P2 定义以主 SKILL 为准；MG01–MG12 只用于定位观察，不是第五把尺，也不含独立严重度体系。

- 加载：完整/里程碑评审按需启用全部适用项；局部迭代只测改动相关项。UI/UX 项随 R02、策略与循环项随 R03、经济与回访项随 R04 执行；R01 仍只收角色卡与净化简报，R06 复核与 R07 唯一台账不变，不新增轮次，不改十节报告与 schema。
- **基准与写法**：匹配子类先读 [能力对照](capability-review.md)（通用主线）与 [经营基准](management-baseline.md)（候选参照起点，不是硬清单）：按三层登记——参照传统实现 → 目标提供/缺/替代 → 玩家能力结果；MG 用于定位具体损害与深度取证，不重复基准表、不新增台账；基准未核条目待补，不因目标未提供功能就不记录。
- 严重度：缺反馈通常 P1；核心承诺被实测否定才候选 P0；表达/内容确实不足且行动已成立才 P2；技术故障独立入 B。不因“没有某功能”判严重度。
- 完成条件：单项完成＝有可复现动作、实际观察记录、条款判定（符合 / 违规 / 未测 / 不适用）与覆盖范围，缺一不算测过；可比对照可复用同版原始证据，复用不算新复现，不为满足编号重复造操作。
- 不做：引擎榜单、代码或渲染性能审查、无入口的案例复述；未实测的机制不得写成事实。
- 3D 经营同时加载 [3D 专项](3d-gameplay.md) 的相关项。

## 一、运行前判定与取样

先读已提供的玩法说明、可见承诺与入口内信息（不读实现代码），固定四项并写进本轮记录：

- **经营对象**：管什么（农场 / 工厂 / 城市 / 餐厅 / 商店 / 主题公园 / 运输网等），及其资源、空间、时间载体。
- **玩家权力**：能改什么（选址、排产、人员、物流、价格、时间控制），哪些只是观察。
- **目标与周期**：单局目标、长期目标、沙盒或表达定位；一次会话的预期长度。
- **已存在及当前版本已承诺系统**：生产链、人员、物流、事件 / 失败、离线收益、扩张与规模机制中，哪些实际存在、哪些当前版本已向玩家承诺；承诺以玩家可见信息为准，不把未来路线当已实现。

判定口径：先按玩家任务与 [经营基准](management-baseline.md) 候选查能力有无与替代，即使未宣传、未承诺也按同类必要任务照查；只有能力本身对当前类型任务不需要且有依据 → 不适用，写体裁或范围理由。未提供传统实现仍在能力对照行登记有无、替代或合理省略理由，不从记录消失；已提供或当前版本已承诺但未能测（本轮未达到、工具或时间不足）→ 未测并说明缺口，不得写成符合，也不得写成缺失；已实证的当前承诺行动链破坏仍按原尺实际损害评。凡条款写“有 X 才测”的，只限定对应动作与深度的执行，能力本身有无先查。只有设计稿或截图、没有可运行入口时：可先完成 [开发准备度](development-readiness.md) 的材料审查；仍不称试玩、不做动态或全局裁决、不评分，只限定可见事实，提待验证候选与待验方案；只有充分对应静态证据的条款才可确认。

严格度按主打体验：主打经营策略的项目（不论难度档）即适用吞吐、边际与退化策略判据；休闲、沙盒、表达或放置经营按承诺体验检查，不强求策略优化。

代表工作流（选择适用节点的取样链，不要求每圈全做；三圈循环仍沿主 SKILL，MG08 等仅在适用条件满足时执行；括号内为本附件对应定位项）：

1. 看状态（MG01）——说出“接下来做什么”所需的当前局面。
2. 找瓶颈（MG05）——依据可见信息指出卡在哪一环。
3. 比较两方案（MG06）——给出成本、风险、时机或表达差异。
4. 建造 / 排产 / 人员物流调整（MG02、MG03、MG04）——实际执行一次调整。
5. 观察成本与世界 / 经济变化（MG05、MG10）——核对执行前后差异。
6. 事件 / 失败恢复（MG08）——一次中断及其恢复。
7. 成长扩张下一圈（MG09、MG11、MG12）——进入更高规模后的新决策。

证据纪律：用可比状态与原始证据核查因果；条件不可比就降低置信度，不把相关性当因果。不擅自改存储、时钟或真实玩家进程；破产、销毁、重置只在获授权的可丢弃存档执行。参照物从 [参照游戏库](benchmarks.md) 第三节选取，记录版本与核验状态。

## 二、检查项

### UI/UX（R02）

- **MG01 经营总览与关键状态**
  - 动作：在一次实际经营决策现场找目标、关键资源与约束；已有总览 / 资源显示才核对其中库存、净流量、容量、成本与时段等能否分清及关键警报；有顾客 / 服务系统时，把已承诺的顾客需求、排队 / 预订或服务目标一并核对。
  - 观察与判据：必要状态未提供或必须离开决策界面才能取得 → 按一C1/U3 实测影响提候选，不因无独立总览免责；有警报时抽查其是否指向问题对象与原因；对一处显示值做账实抽查。看错数字导致错误决策 → U3/I2/N3 P1；同类数字格式不统一但可辨 → U6 P2。
  - 条款与适用：一C1、一B2、U3、I2、N3、U6。按真实决策所需状态判断而非有总览才测；纯单资源计数不测深度；没有警报功能不强迫警报检查。

- **MG02 建造选址与确认路径**
  - 动作：有建造 / 选址系统时：在一处受限或与邻接冲突的地块先看预览中的限制、占地邻接与成本，提交前取消并检查占位、资源与视角恢复；之后合法提交一次建造，观察实际结果与提示。
  - 观察与判据：预览是否标明限制、占地邻接、成本与影响；提交前取消能否无损回到原状态；提交结果是否与提示一致。取消无法回到原状态或看不清代价 → U8 P1；普通管理动作迫使离开游戏、重建核心状态 → 一A1 P0。
  - 条款与适用：一A2、一B2、U6、U8；连续性问题复用一A1。已有撤销或建筑迁移时另测其规则；已告知不可逆按 U8 判预告与确认是否充分，不因缺少撤销判错；规划/建造能力本身的有无与替代先登记能力对照行，“有系统时”只限定上述动作（见 MB05）。

- **MG03 高频选择与上下文保持**
  - 动作：连续执行三次调配 / 购买 / 建造并比较两个方案；切换菜单或面板。
  - 观察与判据：选中对象、输入与阅读位置是否保持；批量 / 快捷键（已有时）在高速操作下是否可发现、安全、结果可对应。必须心算隐藏成本、跨页记字段或反复无决策确认 → U5 P1。
  - 条款与适用：U5、一A1、一A2、一D1；高频但无决策的重复操作引用 U5/G4。已有功能才检查发现性，不因“没做批量”单独判错。

- **MG04 排产、指派与时间控制**
  - 动作：有排产 / 指派 / 时间控制中对应系统时：指派一次排产 / 人员 / 运输任务；中途取消或调整队列优先级；有时间控制时切换暂停 / 倍速。
  - 观察与判据：开始、进行、结束与恢复能否分清等待、暂停、完成和失败；调整后对应时机、成本或结果是否随之改变（取消导致完成时间变化也算有意义）。无法区分长任务状态 → 一B3 P1；宣称可策略控制却所有干预都无法改变对应时机 / 成本 / 结果 → M4 P0（不只看最终产物同名）。
  - 条款与适用：一B1、一B3、M4。多人世界或本就无批量 / 倍速时不强求，只测实际提供的控制；指派/暂停/倍速/队列能力的有无与替代先登记能力行（见 MB09），不强求不等于不记录。

### 可玩性（R03/R04）

- **MG05 生产链供需与瓶颈追踪**
  - 动作：选一条实际存在的链取瓶颈态：生产链如原料 → 加工 → 仓储 → 需求；服务经营如投入 → 顾客 / 订单 → 履约 → 收入 / 满意度或目标 → 再投入。记录各环节实测流量或负荷，并与界面显示核对，逐项排查上游产能、运输、库存上限、顾客需求侧或服务负荷原因。
  - 观察与判据：瓶颈能否按玩家可见信息定位并解释。瓶颈存在但原因 / 出口不明 → N1 P1；资源互不制约、所有配置同解且主打经营策略 → I4 P0。
  - 条款与适用：N1、I4、M1、一B2。有产耗链、订单履约或服务链才测（不默认每个经营都是工厂生产链）；已实现且可操作的物流 / 运输与服务链按实际链与选择照常实测，不因抽象表现或无逐单位走位预先判为 R09 缺口；不可达记未测，仅尚未实现且当前表现无法验证的部分才记 R09 缺口。定价、顾客 / 服务负荷等仅在对应系统存在时加测。满意度或服务目标只引用玩家可见的实际状态与行为证据，不虚构满意度或顾客情绪。只按玩家可见信息反推，不查实现；与文档不一致只形成线索。

- **MG06 两方案取舍与空间价值**
  - 动作：在可比状态下比较两种布置 / 配置方案，再至少到相关第二局面复核并寻找优势反转。
  - 观察与判据：成本、风险、时机与表达后果是否有差异；反转是否出现。核心选项只换名字且主打体验的后果相同 → G2 P0。
  - 条款与适用：G2、N2。取舍也可通过美观表达与叙事成立，不强求数值差异；没有第二方案可比较时标未测，不按“缺功能”定罪；有限样本只证明已测范围。

- **MG07 决策节奏与劳动自动化**
  - 动作：在已测三圈分别记录主动决策、等待段与必做重复步骤；有自动化时再对比手动与自动流程。
  - 观察与判据：已掌握的机械操作仍占主要主动时间且无新信息或选择 → G4 P1；自动化后主打玩法完全消失 → I5 候选 P0；非主打策略的休闲经营按其他承诺回报判断，不因重复单独判错。
  - 条款与适用：G4、I5、N4。节奏检查对所有经营循环适用；无自动化不因缺对比判错；不以点击数或工具 / 代理耗时当决策深度。

- **MG08 事件、风险与失败恢复**
  - 动作：在获授权废档触发一次事件 / 失败并尝试恢复，记录事前预警、失败原因与不同选择的结果。
  - 观察与判据：能否预测与解释；选择是否影响结果。同次失败无应对窗口连续扣罚 → G5 P1；损失或恢复规则不透明 → P1；无法恢复且非已告知终局 → G5 P0。
  - 条款与适用：G5、M1、M4。有事件 / 失败系统才测；真实存档不做毁灭性操作；困难本身不判错。

### 策划设计（R03/R04）

- **MG09 成长解锁的新约束与用途**
  - 动作：解锁一项新内容后，指出它引入的新约束、用途或目标（若承诺含新顾客群或服务目标，一并计入），并实际使用一次新能力 / 容量 / 定制机会。
  - 观察与判据：成长是否改变后续行动。承诺的成长不能改变后续行动 → G3 P0；奖励用途不清 → P1；完成后没有下一步且非明确终局 → G1 P0。
  - 条款与适用：G1、G3、好玩三问第 2 问。有解锁 / 科技 / 等级系统才测，带此限定只作用于动作执行；无解锁时先查成长/规模结构的有无与替代（扩容、资源扩张等）并登记能力行，只有成长本身不需才不适用。

- **MG10 扩张边际与规模复杂度**
  - 动作：连续做两次同类可比扩张，比较占地、维护、人员、物流与需求的变化及回报；复看瓶颈是否迁移。
  - 观察与判据：扩张代价与回报能否按显示比较；新约束是否可读。无法按显示比较 → N3 P1；约束完全不可读 → N1 P1。
  - 条款与适用：N1、N3、I4、一B2。占地 / 维护 / 人员 / 物流 / 需求相关系统存在才启用；增长并非必须越来越难，难度不升不单独判错，只判边际是否可读、是否与承诺一致。

- **MG11 策略退化、雪球与死锁**
  - 动作：在可比状态下至少比较两种策略与两个相关局面，主动寻找使优势反转的反例。
  - 观察与判据：是否被同一解支配、其他路线是否失去作用。已测核心被同一解支配且其他路线失去作用 → N2 P0；真实规则死锁 → N1 P0；有限样本可确认已测范围，范围外记未知，不机械标疑似。
  - 条款与适用：N2、N1、G2。只在主打策略时判断同解伤害；雪球本身不判错，判的是它是否铲除已测选择。

- **MG12 中断回访与长期循环**
  - 动作：用原档离开后回访，核对保存边界、当前目标与待处理事项；检查下一圈动机（长期层）。
  - 观察与判据：必须靠回忆重建行动计划 → P1；无法接续已承诺的长期成长 → U9 P0。
  - 条款与适用：U9、G6、长期层。在线经营与原档接续为通用项；I6–I8 依离线收益承诺启用，I9 仅在存在重置 / 再成长系统时测（重置不等于离线）；不把放置等同所有经营；真实间隔不足标未测，不用清档或调时钟替代；长局投入或跨会话目标存在时，保存/接续即使未宣传也照查（见 MB01），短单局可例外但不免除成果保护与失败提示。

## 四、亮点保护复验（合成例，非实测）

以下仅为方法示意，不对应任何真实项目或实玩结果：某经营原型把“队列内拖拽调整排产优先级”评为候选亮点 L，记录改动前版本的原始证据与保留契约（拖拽后优先级、进行中任务吸收方式、取消恢复）；改动后在另一版本以可比起点重放同一路径，与旧版证据对照，版本分开记录、旧证据保留，异版证据不作为同版复现；通过条件＝保留契约在新版仍成立，并记录差异；若出现“高速下指派结果与显示不符”，生成新候选并引用一B2/U5，不因此删除旧亮点证据，也不宣布全面改善。本附件只提供测法，未知证据不得写成已发生的事实或真人反馈。
