# 经营基准（模拟经营候选参照，按需加载）

本基准面向模拟经营、基地/城市经营与生产调度类评审，是**候选起点而非硬清单**：内容由有限几款作品、平台版本的文档资料归纳（S 编号、核查日与核验状态见 [经营能力研究](../research/management-capability-study.md)），**不是行业强制标准，也不代表每项成熟度已实测**；文档只证明“提供了该能力”，不证明深度、手感、时延或效果。任务需要或换到相近子类（服务经营、城市建造、工厂自动化等）时可增加、合并或删减模块与条目；**不因“目标没提供”删除候选**。样本选择与同约束对照见 [参照游戏库](benchmarks.md) 与 [能力对照](capability-review.md)。

## 一、使用口径

- **三层写法**：每项先写玩家任务，再记“参照传统实现 → 目标提供/缺/替代 → 玩家能力结果”；缺失与替代并列保留，对照结论与 [能力对照](capability-review.md) 一致（实现状态四态＋对照结论五值）。
- **建议类别**：**核心支撑｜匹配常见｜条件增强** 只是初始关注理由，按目标玩家任务调整；不是 P 必备清单，未提供功能不直接判错，也不因“没提供”让候选消失。
- **替代成立**：须按 [能力对照](capability-review.md) 第七节取正证据（同任务、相关不同局面与最强不利例）；“有意创新”不自动成立，单次样本、人体未知与执行故障（B）分开记录。
- **来源纪律**：优先已核 S 编号；社区维护 wiki、发售前博文、特定模式声明与未核验项明确标注，不编研究事实或行业普遍性。
- **覆盖重点**：长期经营接续、3D 观察与键鼠交互、规划建造、资源物流、教学等必须以本表做“有无与深度”比较，不因目标未宣传或未提供就跳过记录。
- **输出**：能力对照矩阵沿用通用 C 行（run 内定位，不是问题 ID），不新增台账、轮次或分数；未测/未核验不写成缺失。

## 二、模块 MB01–MB12

### MB01 会话接续（保存 / 读档 / 自动保存 / 中断恢复）｜建议：核心支撑（长局/跨会话），短单局条件增强

- 玩家任务：中断后回到原行动与成果，跨会话继续经营，不被无提示丢失。
- 参考声明：S15（暂停菜单覆盖旧档或命名新档、读档列表；手册未见自动保存条目，按目标另验）；S14（社区 wiki：滚动 autosave 默认 3 槽，未与 UI 二次核对；后台保存仅 mac/Linux）；S13（异步 fork 保存为工程取舍样本）；S07（live save 云端仅存最新、无历史，属该模式路线）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：查真正保存/恢复、覆盖范围（手动/自动/跨会话）、读档后状态与待办、失败与错误提示；长局投入即使未宣传也候选照查。
- 适用与可接受替代：短单局可例外（仍查中断恢复是否顺畅）；在线持久/永久死亡/无回档路线不自动免检，失去成果与恢复摩擦按玩家任务判；有意无回档不免成果保护。
- 回接：MG12（回访接续）、TD10（原档接续）；U9/G6。

### MB02 观察与相机（平移 / 缩放 / 旋转 / 俯仰）｜建议：核心支撑（3D/空间），2D 或固定概览条件增强

- 玩家任务：看清空间关系、当前场景、高低选址与遮挡，能覆盖大规模经营视角。
- 参考声明：S15（PC 官方手册：边滚或 WASD 平移、滚轮与 Z/X 缩放、中键左右旋转、上下俯仰与 HOME/END 等键，Options 可改）；S14（Factorio 滚轮缩放；R 为实体旋转、非相机——按文档边界记录，不外推所有 2D）；S16（快捷键可查改可重置）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：平移 / 缩放 / 旋转 / 俯仰逐项在行内登记提供、部分、缺失或未核，不只执行已提供项；用大场景定位、小场景细节、高低/多层选址与遮挡、对象查看任务实测。
- 适用与可接受替代：2D/固定概览可用固定视角＋地图图层（如 S15 Info Views 式高亮范围与 forecast 层）等效完成同一任务，不强制自由镜头；键位不同非质量分；缺项照记能力对照行。
- 回接：TD01–TD03；U3/F4。

### MB03 键鼠 / 手柄选中、确认、取消与输入映射｜建议：核心支撑

- 玩家任务：用已支持输入完成进入、执行与取消，映射可发现可预期，防误触。
- 参考声明：S15（左键选择/激活、右键取消当前选择）；S14（Q 清空光标，含取消接线与规划）；S08（主机版径向菜单、自动修路，官方称调整≠简化）；S09（PC 与主机互支持输入说明）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：进入、执行、取消三条路径各实际执行一次，检查取消后状态/资源/焦点恢复与误触防护；查找键位与设置是否可查改。
- 适用与可接受替代：键位、径向菜单、焦点规则是不同实现，相同键位不是标准；只测实际支持的设备，不同键不扣分。
- 回接：MG03、TD04/TD06；U4/U8/一D1。

### MB04 信息总览 / 产耗容量 / 警报与对象定位｜建议：核心支撑（经营）

- 玩家任务：在决策现场取得库存、流量、容量与时段信息，并定位到具体对象与原因。
- 参考声明：S06（统计嵌主界面：顶部按钮、生产建筑、热键入口，分页；不是“常驻整页”）；S13（蓄电池 charge 图、分星球统计与产出统计口径）；S15（手册 Info Views 图层例）；S05（信息层次与最少 busywork 的设计立场）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：在一次实际决策里核对库存 vs 净产 vs 容量三口径、时段与最新变化；警报（若有）抽查能否指到对象与原因，对一处显示值做账实抽查。
- 适用与可接受替代：不要求统一配色、窗口或常驻页面；总览/警报可为条件增强，但有无与替代照记。
- 回接：MG01、TD02；一C1/U3/I2/N3。

### MB05 规划 / 建造 / 蓝图与取消｜建议：核心支撑（建造类），短局匹配常见

- 玩家任务：先规划再施工，避免昂贵试错，能安全取消或分期。
- 参考声明：S03（幽灵蓝图零成本、缺料自动保留、施工/升级工具单击或拖拽；发售前博文，非最终实测）；S14（Shift+左键先放 ghost 预览）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：拆三段核对——规划（预览、占地与邻接）→ 提交代价（资源、时间、缺料行为）→ 施工与取消（提交前取消能否无损恢复）。
- 适用与可接受替代：无蓝图时，短局低成本直接建造或迁移可作替代；先登记传统蓝图有无与替代实际效果，有实证同约束差距才记差距，否则认可已测替代及其限制；已有撤销按实际规则测。
- 回接：MG02、TD06；U8/一B2。

### MB06 资源 / 物流与供需瓶颈｜建议：核心支撑（经营）

- 玩家任务：让资源从产出经运输到使用，指出卡在哪一环并处理。
- 参考声明：S02（原版：资源位置性、自动运输＋紧急手动指定、电力/燃料短缺会中断运输）；S01（Relaunched：无人机范围面板可调、仓库期望数量、火车纳入全局调度/环线/轨道导电、穿梭机全局调度；移除流体为声明，不作替代品质结论）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：选一条实际链，记录各环节流量或负荷并与界面显示核对，逐项排查上游产能、运输、库存上限与需求侧；已实现规则（路径/环线覆盖、期望库存、耗能条件等）按源支持与目标需要核对。
- 适用与可接受替代：不要求 drones/火车/逐单位物流的同款实现；服务经营无实物链时换服务链（投入→顾客/订单→履约→收入/目标），且须按目标自身证据判，不以来源宣称代替。
- 回接：MG05、MB08；N1/M1/一B2。

### MB07 人员 / 服务 / 需求与经营对象调度｜建议：匹配常见（本子类 primary 来源不足）

- 玩家任务：把有限人员、服务或需求分配到对象与时段上做取舍。
- 参考声明：目前无可核一手样本（S01/S02 仅覆盖资源/物流对象侧，人员、顾客与需求侧正文未取得）——候选来源待补，不编做法｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：按目标实际提供的指派/服务系统做一次调度与一次调整，记录等待、完成、失败与需求变化；无该系统先查能力行与替代。
- 适用与可接受替代：工厂式人员链不是所有经营必需；本模块只对照来源齐全部分，缺来源明确待补，不按工厂模板硬套。
- 回接：MG04、MG09；N4/G4。

### MB08 经济选择 / 规则关系与策略深度｜建议：核心支撑（策略经营），休闲/沙盒匹配常见

- 玩家任务：在成本、风险、时机或表达之间做出有后果的取舍。
- 参考声明：primary 文档可抽样本能力——规划占地（S03“建筑空间本身就是资源”）、物流供需（S02）、统计口径（S06、S13）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：在可比状态比较两种策略，再到一个相关局面寻找优势反转，确认真实深度而非选项改名；回接条款 I4/N2/G2。
- 适用与可接受替代：公式与成本收益表非强制，沙盒/休闲可用美观、叙事或表达成立取舍，但仍须有实际后果。
- 回接：MG06、MG11；G2/N2/I4。

### MB09 时间控制 / 长任务 / 队列｜建议：核心支撑（实时经营）或条件增强

- 玩家任务：控制节奏——暂停、加速、排队与取消，使等待可控可读。
- 参考声明：S07（多人 active pause、无加速——该模式特定声明，不推广为单人标配）；S15（Space 暂停、x1/x2/x4 速度）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：逐项列 pause/倍速/队列/取消能力实际有无与结果时机（开始、进行、结束、失败可分辨）；干预是否真正改变时机、成本或结果。
- 适用与可接受替代：多人世界或模式/玩家任务有证据表明不需要时，省略才合理，“没有该功能”本身不作理由，须写依据；能力有无仍登记，有实证同约束差距才记差距，未实证损害不强制 P。
- 回接：MG04；一B1/B3/M4。

### MB10 教学 / 帮助与独立运用｜建议：匹配常见

- 玩家任务：首次需要前学会规则，脱离提示后能独立再用，卡住时能求助并恢复。
- 参考声明：S10/S11/S12（少用打断弹窗、以实验教概念、信息通道定用途、内部测试抓卡死；NPE 因愿景撤换——开发者取舍与成功效果分开）；S16（教学可选、前期任务不可跳过、Advisor 可回看、提示无需动作）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：走一条“初次任务 → 脱离提示独立复做 → 遇阻求助恢复”的路径；查教程/帮助能否重访并用于非教学语境。
- 适用与可接受替代：不强制教程跳过、自动最少点击或特定教学风格；风格与路线差异不单方面判坏。
- 回接：M3/U2/F3；本模块无直接 MG 项，按 R02/R03 承载。

### MB11 成长 / 规模 / 批量与自动化｜建议：核心支撑（长期经营）或条件增强

- 玩家任务：规模变大后仍可管理，重复劳动由批量或自动化承接。
- 参考声明：S06（Shift 拖拽多重复制、统计入口）；S13（分星球统计＋全局开关、计入产能加成后的产量口径，不含画质设置）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：比较最小已解锁与更高一级两个规模的重复操作、信息负担与仍可管程度；功能缺也列候选差距与替代。
- 适用与可接受替代：自动化/批量不是所有经营必需（放置、休闲按承诺判），但“规模增长后仍可管”按玩家任务判；不设统一数值阈值。
- 回接：MG07/MG09/MG10；G3/G4/I5。

### MB12 失败恢复 / 防错与成果保护｜建议：匹配常见或条件增强

- 玩家任务：误操作与事故可安全返回或取消，损失有预告，已验证成果不因改动丢失。
- 参考声明：S15（覆盖旧档为显式选择；手册未写覆盖确认，不猜确认框）；S06（曾修“读档崩溃”类问题——只证明出现过并修复，不证现状稳定）｜[S 台账](../research/management-capability-study.md)。
- 目标有无与深度测法：在获授权废档测取消/返回与损失预告；覆盖式保存的保护与提示按目标另验；改动后按回归卡重验已确认亮点。
- 适用与可接受替代：无毁灭事件不强求；恢复能力仍按玩家任务判；执行故障入 B、体验损害按四尺 P。
- 回接：MG08/MG12、TD10；G5/G6/U8。
